# Journal de calibration — tests terrain étiquetés

Chaque test : Anthony fait une manche devant sa caméra, puis dicte le
résultat. On consigne vérité terrain + lectures, pour calibrer les seuils
et la baseline individuelle. Aucune vidéo conservée — que les chiffres
et les étiquettes.

## Protocole
1. Baseline 20 s : vérités calmes (nom, ville, repas).
2. Manche vérités : récit vrai détaillé, 30-60 s.
3. Manche mensonges : affirmations fausses, même ton, 30-60 s.
4. Dicter après chaque manche : indice %, confiance %, étiquette.
